PeopleComfort

Shared interiors can contain different thermal conditions while their future user composition is uncertain. PeopleComfort compares fixed seating-capacity configurations across explicit user mixes. It evaluates each configuration with a pinned CBE PMV implementation, exact feasible assignment and minimax regret. The tool is an illustrative research prototype; bundled conditions are constructed, not observed.

The software separates the physical decision (how many seats each zone receives) from the operating assumption (how people are assigned after their mix is known). It provides full input and result ledgers so a ranking can be inspected and rerun. The package is installed from a local repository checkout and is not on PyPI.

Try it in your browser

Open the interactive thermal workbench to edit the zone temperatures, MRT, air speed, humidity, activity, clothing, PMV threshold, capacity alternatives and compositions. The page uses the pinned CBE formula in your browser and shows PMV/PPD for every profile-zone pair. Its starting thermal conditions are hypothetical; replace them with documented data before making a site-specific claim. The default case matches the revised seven-design A3 report.

Workflow

1. Define the space and profiles — specify two thermal zones, activities, clothing and access.

2. Define designs and compositions — hold total seats constant and distinguish development from holdout mixes.

3. Calculate and allocate — run CBE calculations and exact constrained matching.

4. Compare decisions — compare existing, baseline and robust choices.

5. Stress-test and export — inspect uncertainty, files and limitations.

For the expanded method, read the General evaluation framework. Start with Quick start, then see the workflow guide, Python API or CLI reference.
