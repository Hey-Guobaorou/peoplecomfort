CLI reference

The installed package exposes one command, peoplecomfort, with two subcommands. python run.py uses the same parser from a source checkout. Run peoplecomfort --help and peoplecomfort <subcommand> --help for the installed version.

CommandPurpose
peoplecomfort analyzeEnd-to-end scenario comparison and file export
peoplecomfort serveLoopback-only local browser interface

The CLI accepts local inputs and performs no runtime download. The calculation launches bundled CBE JavaScript in Node.js. The workflow guide explains the research meaning of each stage.
